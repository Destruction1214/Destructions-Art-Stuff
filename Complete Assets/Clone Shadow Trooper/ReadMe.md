Description:
Clone Shadow Troopers were special ops clones serving similar tasks as ARCs and Clone Commandos. Serving during the Clone Wards and later in the Empire, they would be the template for Shadow Stormtroopers and Storm Commandos.
Includes a Base Variant and 5 ARC variants.

Needed:
- Animation Overrides from Fall of the Republic
- various Clone Textures from Fall of the Republic

Additional Notes:

- use TrainedJetpack.alo / TrainedJetpackHero.alo for the <Land_Model_Anim_Override_Name> on Shadowtrooper_Jetpack.alo
